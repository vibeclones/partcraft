# partcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [partcraft](https://github.com/getcadcraft/partcraft), by CadCraft. The newest version lives at getcadcraft.com/use/partcraft; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: Apache-2.0.

- Latest: `/partcraft/latest/`
- Specific version: `/partcraft/v<version>/`
- Version list: `/partcraft/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
